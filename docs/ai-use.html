STAT 330 / Project Checkpoint

AI Use and Verification Plan

Preliminary disclosure for the STAT 330 project checkpoint

How AI has been used

As described in our project proposal, AI has helped with debugging R code, improving wording, organizing the proposal, and identifying possible regression extensions. Our group is responsible for reviewing research questions, data choices, predictors, and final modeling decisions.

Proposed AI-assisted extension

Compare ridge and LASSO regression with our baseline multiple linear regression model. We plan to explore whether shrinkage improves prediction and helps with correlated predictors such as shots, passes, corners, and dribbles. If feasible, we will use repeated cross-validation to assess out-of-sample performance.

Any code or methods suggested by AI will be treated as provisional until we review and test them.

Two planned verification checks

1. Independently inspect the code and the data pipeline. We will check AI-suggested R code against the documentation for the relevant packages, confirm that variables are built using the intended StatsBomb event definitions, verify that each team-match is represented once, and inspect whether preprocessing creates data leakage across training and validation splits.

2. Reproduce and compare the model results. We will rerun the proposed extension with a fixed random seed and the same cross-validation splits, compare out-of-sample prediction errors (such as RMSE or MAE) with the baseline model, and investigate any unstable or implausible coefficients or predictions. We will not use AI-generated claims as findings without verifying them against the computed results.

Current status

These checks are planned, not yet completed. Final code, diagnostics, results, and any revised AI disclosure will be added as the analysis proceeds.
